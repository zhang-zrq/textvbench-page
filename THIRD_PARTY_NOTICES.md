## Motion controller

The motion-controller script in `templates/motion-controller.js` is adapted
from the installed **diagram-design** skill's
`assets/template-motion.html`. The source skill declares the MIT license.
Local extensions add accessible stage tabs and synchronize direct selection
with playback, keyboard navigation and static fallbacks. The adapted script
is embedded in the generated standalone walkthroughs. Website
content, example scenes, data views, and styling were authored for TextVBench.
`templates/frame-sequence.js` is a local extension implementing sampled-frame
playback and synchronization with the observation table.
